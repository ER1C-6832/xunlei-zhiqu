## 迅雷智取 Competition Prototype

推荐环境：

- Windows 10 / 11 x64
- Chrome / Edge

Release Assets：

- `XunleiZhiqu-Setup-x64.exe`
- `XunleiZhiqu-Portable-x64.zip`
- `XunleiZhiqu-Extension.zip`
- `SHA256SUMS.txt`

这是可独立安装的比赛产品原型。安装后的普通使用不需要 Python、Node.js、pnpm、uv、Git 或源码仓库。

### 使用

1. 安装并启动 `XunleiZhiqu-Setup-x64.exe`；
2. 安装浏览器扩展；
3. 打开真实下载页面；
4. 使用 Side Panel 智能分析、确认资源并创建真实下载任务；
5. 在自动打开的 Task Center 中查看、暂停和继续下载。

当前主要支持普通 HTTP / HTTPS 文件型资源。Magnet / Torrent / HLS / DASH 等不由 Competition Prototype 当前 Executor 执行。

### AI 与安全边界

Node A 负责第一次资源理解与选择；Node B 负责来源失效后的语义找回；真正的下载、Range Resume、来源验证和 Source Switch 由本地确定性 Runtime 执行。

AI 的语义判断不等于可以安全拼接旧 `.part` 的证明。
