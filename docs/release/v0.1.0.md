# 迅雷智取 v0.1.0

迅雷智取的首个公开版本。

迅雷智取是一款面向复杂下载页面的智能资源下载工具。它会先理解页面中的版本、系统、架构、安装形式、媒体规格和附件差异，再让用户确认真正需要的资源，并由本地 Runtime 完成真实下载、断点续传和来源恢复。

## 主要功能

- Chrome / Edge Manifest V3 浏览器扩展；
- 智能整理软件下载页、Release 页面、镜像站、图片页和普通文件页；
- 根据当前设备给出可解释、可修改的资源推荐；
- HTTP / HTTPS 真实本地下载；
- `.part` 临时文件与 HTTP Range 断点续传；
- SQLite 任务持久化，Runtime 重启后保留任务和下载进度；
- 多资源 / 多 Asset 下载任务；
- 下载失败诊断与一次同来源轻量重试；
- 原来源不可用时，可在当前打开的其他页面、镜像或 CDN 中重新寻找同一资源；
- Node B 负责语义匹配，本地 Runtime 通过长度、Range 和 `.part` 字节抽样确定是否允许跨来源续传；
- React 下载任务中心，集中查看下载进度、暂停、继续和来源恢复状态。

## Windows 安装

支持 Windows 10 / 11 x64。

推荐下载：

- `XunleiZhiqu-Setup-x64.exe` — Windows 安装包；
- `XunleiZhiqu-Portable-x64.zip` — 免安装便携版；
- `XunleiZhiqu-Extension.zip` — 浏览器扩展独立包；
- `SHA256SUMS.txt` — Release 文件完整性校验。

安装包已经包含本地 Runtime、任务中心以及浏览器扩展文件。首次使用浏览器扩展时，受 Chrome / Edge 本地扩展安装策略限制，仍需要在扩展管理页确认一次“加载已解压的扩展程序”。安装助手会打开对应页面和扩展目录。

普通用户不需要安装 Python、Node.js、pnpm、uv、Git 或源码仓库。

## 使用方式

1. 安装并启动迅雷智取；
2. 按安装助手完成 Chrome / Edge 扩展加载；
3. 打开一个真实下载页面；
4. 在迅雷智取 Side Panel 中点击“智能分析”；
5. 查看资源说明并确认需要的文件；
6. 创建下载任务；
7. 在任务中心查看进度、暂停或继续下载。

如果原来源失效，可以选择“一键续取 / 寻找其他来源”，进入另一个相关页面后使用“在当前页面寻找”。新来源必须通过本地确定性验证后才能从已有 `.part` 继续。

## AI 与执行边界

迅雷智取采用两个语义节点和一个确定性本地执行层：

- Node A：第一次理解页面资源并帮助用户选对文件；
- Node B：原来源变化后，在用户当前页面重新找到原资源；
- Runtime：真实下载、失败诊断、Range Resume、来源验证和 Source Switch。

AI 的判断不会直接授权磁盘写入或旧 `.part` 拼接。真正的执行许可始终由本地 Runtime 决定。

## 支持范围

当前主要支持普通公开 HTTP / HTTPS 文件型资源，包括软件安装包、压缩包、文档、图片、普通媒体、大文件、Redirect、CDN 和支持 Range 的镜像来源。

当前不执行：

- Magnet / Torrent；
- HLS / M3U8；
- MPEG-DASH；
- `blob:` URL；
- DRM 内容；
- 需要绕过登录、CAPTCHA、防盗链或其他站点安全机制的资源。

## 隐私

完整 Source URL、Cookie、Authorization、signed token、本地绝对路径、`.part` 内容和下载执行状态属于本地执行层，不应进入模型 Prompt。来源切换的最终验证也始终在本地完成。

## 校验

下载 Release Assets 后，可使用 `SHA256SUMS.txt` 核对文件完整性。
